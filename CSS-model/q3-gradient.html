Gradient Backgrounds

Linear Gradient

This section blends colour smoothly along a single straight line, moving diagonally from a deep blue to a bright teal. Declared with background: linear-gradient(135deg, #1b2a4a, #16a085);

Radial Gradient

This section radiates colour outward from a central point, like light from a source, fading from warm orange at the centre to deep maroon at the edges. It also uses background-attachment: fixed;, so the gradient stays still while the page scrolls over it — a subtle parallax effect.
